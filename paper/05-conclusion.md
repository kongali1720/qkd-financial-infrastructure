# Chapter 5 - Conclusion and Future Work

## 5.1 Conclusion

QKD and PQC offer complementary approaches to protecting communications against selected quantum-era threats.

QKD provides a physical approach to secret key establishment, while PQC supports scalable cryptographic migration using conventional computing platforms.

Neither technology eliminates the need for strong authentication, secure endpoints, governance, and sound implementation.

## 5.2 Future Research

1. Build a laboratory key-management prototype.
2. Evaluate standardized PQC implementations.
3. Model QKD-assisted protected interbank links.
4. Compare deployment costs and security assumptions.
5. Test cryptographic agility and failure recovery.
6. Develop an independently reviewed threat model.

## 5.3 Final Statement

The proposed framework is a research architecture and requires further technical validation before any real-world financial deployment.
